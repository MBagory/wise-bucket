# Try milestone M0 yourself

**What M0 delivers:** an installable `wise-bucket-server` binary. `setup` provisions a local PostgreSQL + pgvector and declares your recording folders (data roots). `init` configures a robot repository for Claude Code. `server_info` answers inside Claude Code, and `doctor` checks everything.

**Success means:**

- following only the docs, a clean macOS or Linux machine reaches a working `server_info` in Claude Code that lists the roots you declared;
- `doctor` is clean;
- two Claude Code windows work at once;
- PostgreSQL stops when the last window closes;
- your own PostgreSQL works too.

About 10 minutes.

## Steps

1. **Build and install**

   ```sh
   cargo install --path crates/wb-server --locked
   wise-bucket-server --version
   ```

2. **Setup** (answer the questions; add one or two of your real recording folders)

   ```sh
   wise-bucket-server setup
   ```

   ✅ Expect: PostgreSQL 17 + pgvector 0.8.6 ready, your roots listed with a count of candidate recordings.

3. **Initialize a robot repository**

   ```sh
   cd <your robot repository>
   wise-bucket-server init --robot <robot name>
   ```

   ✅ Expect: `.wisebucket/config.toml` and `.mcp.json` created.

4. **Claude Code**: run `claude` in that repository, approve the `wise-bucket` server, run `/mcp`, then ask *"call server_info"*.

   ✅ Expect: version, `database: managed · PostgreSQL 17.11 · pgvector 0.8.6 · 1 active session(s)`, your project, default robot and roots.

5. **Check the installation**

   ```sh
   wise-bucket-server doctor
   wise-bucket-server config show --origin
   ```

   ✅ Expect: no failed check; each value shows where it comes from.

6. **Two windows**: open a second terminal, run `claude` again in the same repository, ask for `server_info`.

   ✅ Expect: `2 active session(s)`. `wise-bucket-server db status` lists both clients.

7. **Stop after the last session**: quit both Claude Code windows, then:

   ```sh
   wise-bucket-server db status
   ```

   ✅ Expect: `running  no`.

8. **Try to break it (optional)**
   - `wise-bucket-server roots add inner <a subfolder of a root>`: refused with `root_overlap`.
   - Rename a root folder, then run `doctor`: fails with `root_invalid` and a documentation link.
   - `wise-bucket-server backup /tmp/wb.dump`, then `restore /tmp/wb.dump --yes`.

9. **Your own PostgreSQL (optional)**, for example with Docker:

   ```sh
   docker run -d --name wb-pg -e POSTGRES_PASSWORD=pw -p 127.0.0.1:55432:5432 pgvector/pgvector:pg17
   export WB_DATABASE_URL=postgres://postgres:pw@127.0.0.1:55432/postgres
   wise-bucket-server --state-dir /tmp/wb-byo setup --yes
   wise-bucket-server --state-dir /tmp/wb-byo doctor
   ```
