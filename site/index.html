Long-term context and insights for your time-series data

Wise Bucket is an open-source MCP server for R&D teams. It connects the AI agent you already use to the recordings on your machine (robot bags, flight logs, CAN traces, measurement files) and answers its SQL in milliseconds.

$ curl --proto '=https' --tlsv1.2 -LsSf https://github.com/MBagory/wise-bucket/releases/latest/download/wisebucket-installer.sh | sh

How it works

Decoded once. Queried in milliseconds.

Each recording is decoded once, in the background, into Parquet files on your machine. Your agent queries all of them with SQL through Apache DataFusion: only the answer comes back to its context, while full-resolution signals go straight to your viewer.

Why Wise Bucket

Your agent, fluent in your recordings

Built for time series

Telemetry, logs and measurements, from robot bags to CAN traces. Every stream becomes a table with a common nanosecond time column.

Bring your own agent

Use the agent you already work with, with its model and your subscription. It finds abnormal and similar recordings by comparing each one with its peers.

Frugal with tokens

A fuller context window is slower, costlier and less accurate. Your agent's SQL runs on your machine and only the answer comes back.

Built for speed

Written in Rust, on Apache DataFusion and Apache Parquet. Answers across all your recordings, in milliseconds.

Instant display in your viewer

Your agent opens the original recording at the right time in your viewer, and sends any query result straight to Rerun, at full resolution.

Long-term context

Tell your agent what the files don't say: the machine, what changed, the conditions, the purpose of a test. Wise Bucket keeps it for every later session.

Formats

Reads the logs of robots, drones, vehicles and boats

A format ships only when an existing Rust crate decodes it. Files Wise Bucket can't read yet are listed as unsupported, never skipped silently.

Robots

  • ROS 2 bags: MCAP or SQLite .db3
  • MCAP with ROS 2, protobuf or JSON messages

Drones

  • PX4 ULog
  • MAVLink telemetry logs .tlog
  • ArduPilot DataFlash logs .bin

Vehicles and test benches

  • Vector CAN logs (ASC, BLF), decoded with your DBC files
  • MDF4 measurement files .mf4

Boats

  • NMEA 0183 logs .nmea
  • NMEA 2000 captures (canboat PLAIN .raw)

Tables

  • CSV and JSON Lines
  • Parquet and Arrow IPC

Get started

Try it in two minutes

No database to install, nothing running when no agent session is open.

  1. 1

    Install

    On macOS or Linux, then open a new terminal. Run it again to update.

    $ curl --proto '=https' --tlsv1.2 -LsSf https://github.com/MBagory/wise-bucket/releases/latest/download/wisebucket-installer.sh | sh
  2. 2

    Set up

    Once: it asks which folders hold your recordings.

    $ wisebucket setup
  3. 3

    Connect your agent

    Once, with the command setup prints. Claude Code below; for Codex, Cursor and Cline, see Connect your agent.

    $ claude mcp add --scope user wise-bucket -- ~/.cargo/bin/wisebucket serve
  4. 4

    No recordings at hand? Fetch samples

    About 4 MB of public samples, fetched from their upstream projects and checked against pinned SHA-256 checksums.

    $ wisebucket demo --all
  5. 5

    Ask, in a new agent session

    • ulog

      “When does CPU load peak, and what runs then?”

    • can

      “Which CAN IDs are on the bus, at what rate?”

    • nmea2000

      “How did the apparent wind change during the tack?”

Private by design

Your recordings stay on your machine

Wise Bucket runs locally, for one engineer, next to the agent. Only the tool results your agent sends to its own model leave the machine, under your agent's terms.

No model calls

Wise Bucket never contacts an LLM. Your agent owns the model, your key and your token budget.

Read in place

Recordings are never uploaded, modified or moved. The decoded copy lives on your machine; delete it any time.

Read-only SQL

Writes and file access are refused. Each query is capped at 30 s, 1 GB of memory and about 60 KB of results.

No network at runtime

Only demo downloads files: public samples, each verified against a pinned checksum.
