# 0007. No release before the MVP; install from source

**Date:** 2026-10-03 · **Status:** Superseded by [0015](0015-first-release-after-m1.md)

## Context

A 0.1.0-rc.1 pre-release with an installer was published during M0, before Wise Bucket could do anything useful with recordings.

## Decision

The pre-release was withdrawn. No release until the MVP, then planned as milestone M4; until then, install from source.

## Alternatives

- **Keeping the pre-release:** it invited use before anything worked.

## Consequences

- The milestone plan was later replaced by a list of possible features ([0014](0014-possible-features-instead-of-milestones.md)), leaving "M4" undefined: the release decision was made again in [0015](0015-first-release-after-m1.md).
