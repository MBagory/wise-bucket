# 0006. Skills deferred

**Date:** 2026-10-03 · **Status:** Accepted

## Context

A first design made **skills** (short methodology playbooks: designing a discriminating test, aligning clocks, comparing rounds…) the first milestone after M0, served over MCP or as native Agent Skills.

## Decision

Skills are **deferred** until a design decision is made: how they are delivered (served over MCP, native Agent Skills, or both), where team skills live now that Wise Bucket is user-wide only ([0004](0004-user-wide-only.md)), and how built-in content is reviewed.

## Alternatives

- **Skills as the next milestone:** set aside to deliver access to the data first.

## Consequences

- Wise Bucket serves no skills. They remain on the list of possible features ([0014](0014-possible-features-instead-of-milestones.md)).
